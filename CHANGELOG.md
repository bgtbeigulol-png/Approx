# Changelog

All notable changes to Approx are documented in this file.

## [0.1.0-beta.1-f1] - 2026-08-08

- Added `/cd` directory browsing and workspace switching.
- Added manual and automatic context compaction with animated progress.
- Added Go/Plan modes, persistent task progress, and model-managed planning notes.
- Added structured questionnaires with keyboard navigation and free-form answers.
- Improved queued notes, overlay ordering, and compact/questionnaire presentation.
- Split the application controller into focused modules.
- Fixed Windows Terminal IME preedit flicker with event-driven rendering and a native cursor.

## [0.1.0-beta.1] - 2026-08-07

Initial public beta.

- Added the Approx terminal interface backed by Pi.
- Added persistent conversations, model and effort controls, Plan Mode, and
  structured questions.
- Added Windows-first installation and first-run provider setup.
- Requires Node.js 22.19 or newer.
